# Real Chat UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the messages placeholder with a bilingual, in-page chat client backed by the authenticated chat API.

**Architecture:** A strict same-origin route validates the exact public chat request before forwarding it to the server-only API URL. A client component owns the selected public IP ID, page-local messages, and provider conversation ID; no state is persisted across refreshes.

**Tech Stack:** Next.js App Router, React 19, `@aifans/contracts`, Vitest, Testing Library.

## Global Constraints

- Modify only `apps/web/**`.
- Do not invent an IP list or claim persistent memory.
- Only POST `/api/chat/:uuid/messages`; forward cookie and request correlation.
- English and Simplified Chinese must have identical chat message keys.
